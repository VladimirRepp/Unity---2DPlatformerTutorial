# Unity---2DPlatformerTutorial
Простой пример 2D платформера с видом сбоку и с видом сверху

Данный материал построен так, что в каждой новой сцене добавляется новый функционал, чтобы показать постепенный прогрес 
Сцена 1:
- игрок движение и прыжок)
- платформы
- кнопка далее
- вся графика примитивы = image
Сцена 2:
- компонент для сбора предметов (Pickaups)
- Игровой объект - монета
- Игровой объект - брилиант
- Отображение собранных монет
Сцена 3:
- Система квеста (условие перехода на следующий уровень)
Сцена 4:
- анимация персонажа (Idle, Run, Jump, Fall)
Сцена 5:
- Визуал акружения через Tilemap
  - Платформы
  - Передний план
  - Задний план
- Заменилир скины монетки и брилианта
- Добавили эффекты монеткам и брилиантам (VFX)
- Слеженее камеры за игроком (с ограничениями зоны видимости)
Сцена 6:
- Паралакс для заднего фона
- Эффекторы для платформ (ВАЖНО: на колайдере платформы указать что используем с эффектором)
Сцена 7:
- UI панель паузы
- UI панель конец игры
- зону проигрыша
- менеджера UI
